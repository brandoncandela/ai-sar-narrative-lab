      How it works

      Built so the key never leaves the laptop

      Generation runs once, locally, with the API key in an environment variable. Only the drafts and their scores are committed. This page is static files.

      1. Evidence packet24 fictional cases from the AML Backlog Command Center. Every fact gets an ID: KYC, CASE, or the alert ID.
      2. Draft with ClaudeStructured output forces who, what, when, where and why, with a citations list on every sentence.
      3. Check with rulesAmounts, dates, alert counts, branches, ZIPs and accounts must appear in the evidence the sentence cites.
      4. Plant errorsEight kinds of mistake are injected into copies of each draft to prove the checks fire.
      5. ReviewAccept, edit or reject with a reason. Edits are scored again by the same rules.
      6. PublishStatic page on GitHub Pages with a policy that blocks outside connections.
